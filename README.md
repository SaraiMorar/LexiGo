# LexiGo · 英语词组背诵系统

本地运行的英语背诵工具：以**批次**为单位（你每次给的一坨词就是一个批次），新词双向学习（中译英 / 英译中），不会的词循环到掌握；之后按 SM-2 记忆曲线自动安排复习。完成与否只看**实际有没有学完**，不看日期——哪怕只学了一个词，也绝不会误判"今日已完成"。数据全部保存在本地 SQLite。

## 一、启动方法

**方式一（推荐）**：双击项目目录下的 `run.bat`，会自动启动服务并打开浏览器。

**方式二**：在项目目录下，用 `.venv` 环境运行：

```powershell
C:\Users\Administrator\pythonProject\Softwares\LexiGo\.venv\Scripts\python.exe app.py
```

看到 `Running on http://127.0.0.1:5000` 后，浏览器打开：

```
http://127.0.0.1:5000
```

关闭终端窗口（或按 Ctrl+C）即停止服务。

## 二、学习流程（以批次为单位）

1. 首页显示**待学新词**数、**到期复习**数，以及每个批次的进度（如「第 1 批 0 / 92」），点击「开始学习」；
2. **新词阶段**
   - 第 1 轮：看中文想英文（中译英），空格翻面，按 `1/2/3/4` 自评；
   - 第 2 轮：看英文想中文（英译中）；
   - 评「不会 / 模糊」的词进入错词循环，双向交替反复出现，直到全部达到「记住 / 掌握」；
3. **复习阶段**（新词全部毕业后自动开始）
   - 到期的旧词，同样先中译英、再英译中；
   - 「不会」的词当天重做，直到掌握；
4. 结束页查看统计、连续打卡和明日到期数。

**关于批次**：

- 每次同步 CSV 时新增的词，自动归为一个新批次（第 1 批、第 2 批……）；
- **两种开始方式**：点底部「开始学习」会把所有未学批次按顺序走完；直接**点击首页任意一个批次行**，则只学这一个批次（鼠标悬停有"点击只学这个批次"提示，已学完的批次置灰不可点）；
- **不限制每天学几个批次**：单批学完后可再点其他批次，学累了关闭，断点保留、下次继续；
- 完成后又给了新一批词，随时可以再开始，不会被"今天已经学过"挡住；
- 只有真正没有待学新词、也没有到期复习时，才显示"当前全部完成"。
- 中途切换批次再回来时，会继续尚未通过的方向和错词；两个方向都通过才计入批次「已学完」。
- 搁置的词会同时退出当前学习队列，恢复后可重新开始；进度条只统计当前任务已通过的卡片，错词重做不会提前填满。

评分提交期间按钮会暂时禁用；多标签页或网络重试遇到已变化的学习状态时，页面会刷新卡片并要求重新翻面，避免误评下一张卡。评分、排期、学习日志与断点会在同一事务中保存。

**当前词库构成（共 1526 词、30 个批次）**：

- 「第 1 批」：原有 92 个作文句型 / 词组；
- 「A 核心单词」「A 重点词组」……「T 核心单词」「T 重点词组」：来自《备战高考英语高频核心词汇》，
  按字母 A–I、M、O、P、S、T 划分，每个字母的核心单词、重点词组各成一个批次，共 28 个批次；
- 「华二卷词汇整理」：来自《华二卷词汇整理.docx》，47 个词组，自动跳过表头「英文 / 中文」；
- 各文档内重复出现的词条已自动去重，只保留首次出现的记录。

## 三、评分含义

| 按键 | 等级 | 效果 |
|---|---|---|
| 1 | 不会 | 当天重来，间隔清零 |
| 2 | 模糊 | 间隔缩短 |
| 3 | 记住 | 按标准曲线推进（1→3→6→15→30→60 天） |
| 4 | 掌握 | 间隔大幅拉长（30/60/120 天抽查） |

请如实评分，把判断交给系统，不要提前或延后。

## 四、词库管理

顶部导航点「词库」，可以在网页上直接管理：

- **搜索**：按英文 / 中文 / 备注模糊搜索；
- **筛选**：按标签、类型（单词/词组/句型）、状态（未学/学习中/复习中/已掌握/已搁置）过滤；
- **按批次整理**：首页批次名称旁的铅笔按钮可直接重命名（已学完的批次也支持）；批次区域随屏幕宽度自动增加列数，宽屏最多 6 列。词库页选择批次即可查看该批次的词或重命名；列表显示所属批次，支持英文 A–Z 和按类型排序；
- **调整归属**：编辑词条时可移动到其他批次，保留词条 ID、卡片和复习记录；加词默认沿用当前筛选批次（未筛选时沿用最近批次），选择「新建批次」才会创建；
- **加词**：点「+ 加词」，选类型后填写；选「单词」才会出现音标、词性字段，词组和句型不需要；
- **编辑 / 删除**：每行可编辑（回填后修改）、删除（连带卡片和复习记录，需确认）；
- **搁置 / 恢复**：「搁置」后该词不再参与复习（与「已掌握」的超长间隔抽查不同），点「恢复」可重新安排。

也可以继续用以下方式加词：

- 每天把新词发给我，我追加到 `data/words.csv` 并同步；
- 自己用 Excel 编辑 `data/words.csv`，保存为 **CSV UTF-8**，下次启动自动导入（已存在的不会重复）。

**批量导入课堂词组（无需保存文件）**：

1. 在首页或词库页点击「导入批次」，填写新批次名称；
2. 从 Excel、Word 或聊天内容中复制中英表格，粘贴原文，点击「识别并预览」；
3. 检查英文、中文和备注，可以直接修改识别结果，或取消勾选不需要的行，再点「确认导入」。

支持制表符表格、CSV、Markdown 表格和每行一组的 `look after 照顾` 文本。会识别表头、序号、中文在前的表格以及一行多组中英列；从网页或 Word 复制的 HTML 表格会先提取单元格文本。识别不完整的行会保留在预览中，修正或取消勾选后才能导入。

每次最多 1000 条、10 万字符；一批词只创建一个新批次，并生成双向学习卡。已有词条（忽略英文大小写和多余空格）与本次重复项默认不勾选；导入时仍会检查重复，保留旧词条的释义、所属批次和学习进度。全部重复或保存失败时不会留下空批次。新批次不会打断当前学习，可以导入后点「查看新批次」。

CSV 同步以数据库中的学习数据为准：网页删除或改名的旧词不会在下次启动时重新出现；需要重新添加时可在网页主动加词。首次同步旧数据库时仅记录 CSV 基线，保留现有内容；此后修改 CSV 会更新尚未在网页改动的字段，网页修改优先，复习进度不变。CSV 移除行不会删除数据库词条。

仓库的 `data/words.csv` 仅含最初 92 条，并非完整词库。完整备份请使用「备份数据库」；「导出 CSV」可导出全部词条及批次名称、背诵顺序，导入空数据库时恢复分组，但不包含学习进度或删除记录。

CSV 列说明：

| 列 | 说明 |
|---|---|
| item_type | `word` 单词 / `phrase` 词组 / `sentence` 句型 |
| en | 英文内容 |
| zh | 中文释义 |
| phonetic | 音标（仅单词填写） |
| pos | 词性（仅单词填写） |
| tag | 主题标签，如「数字阅读」「直播购物」 |
| note | 备注 / 例句（可空） |
| batch_name | 批次名称（可空；导出时携带，导入新词时按名称分组） |
| order_mode | 批次顺序：`sequence` / `shuffle` / `reverse`（可空） |

## 五、学习统计与导出

顶部导航点「统计」：

- 顶部卡片：词库总数、已学、已掌握、遗忘率、连续打卡、累计评级；
- 近 30 天学习柱状图（新学 / 复习 / 遗忘，堆叠显示，鼠标悬停看明细）；
- 近 90 天活动热力图（颜色越深活动越多）；
- 未来 7 天每天到期数量。

**导出备份**（词库页右上角）：

- 「导出 CSV」：下载全量词库 `lexigo_export.csv`；
- 「备份数据库」：下载完整 `lexigo_backup.db`（含全部进度，恢复时替换 `data/lexigo.db` 即可）。

## 六、考前突击

顶部导航点「突击」：

- 输入抽取数量（默认 30），点「开始突击」；
- 系统优先抽取**遗忘次数多、难度系数低、到期早**的词，双向测试（先中译英、再英译中），评分照常更新排期；
- 若当前常规学习未完成，开始前会提示（已评分记录不会丢，只是中断当前队列）。

## 七、文件说明

```
run.bat                 一键启动（推荐）
app.py                  程序入口（含全部 API）
lexigo/                 核心逻辑（数据库、批次、调度算法、会话、导入）
data/words.csv          词库源文件
data/lexigo.db          学习数据（自动生成，备份时复制此文件即可）
templates/、static/     网页界面（离线零依赖，图表为纯 CSS）
```

数据库主要表：`batches`（批次）、`phrases`（词条）、`cards`（双向记忆卡）、
`review_logs`（每次评级记录）、`session_state`（当前会话断点）。

## 八、主题与暗色模式

- 首次打开**自动跟随系统**的浅色 / 深色设置；
- 点击导航栏右上角的太阳 / 月亮图标可手动切换，选择会被记住，下次打开保持；
- 想恢复跟随系统：在浏览器控制台执行 `localStorage.removeItem("theme")` 后刷新。

## 九、注意事项

- 学一半关掉没关系，重新打开会从断点继续，不重复、不遗漏；
- 即使背到凌晨跨天，进度也不会重置，同一批词同一天到期；
- 数据只在本机，不联网、不上传；
- 若页面异常，先确认 `run.bat` 的服务窗口还在运行，再刷新页面。

## 开发验证

安装 `requirements.txt` 后运行 `python -m unittest discover -s tests -v`。测试使用临时 SQLite 数据库，不修改现有词库或进度；前端交互测试用 `node tests/test_study_ui.cjs`，语法可用 `node --check static/app.js` 检查。
